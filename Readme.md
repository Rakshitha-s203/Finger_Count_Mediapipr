The Finger Count project is a real-time computer vision application that uses a webcam to detect and count the number of fingers shown by a user. It is built using Python, OpenCV for video capture and image processing, and MediaPipe for hand landmark detection. The system captures live video frames from the camera, detects the hand using MediaPipe’s hand tracking model, identifies 21 key landmark points on the hand, and determines which fingers are raised based on their positional relationships. The total number of raised fingers is then displayed on the screen along with the FPS for performance monitoring. To run this project properly, a virtual environment (venv) should be created to manage dependencies separately from the system Python. First, install Python 3.10, then navigate to the project folder and create a virtual environment using python -m venv .venv, activate it using .venv\Scripts\activate (Windows), upgrade pip with python -m pip install --upgrade pip, and install required libraries such as mediapipe and opencv-python. This ensures a clean, isolated setup where package conflicts are avoided and the project runs reliably.
